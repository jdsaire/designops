Sources: Sackett et al. (2022) on selection validity; Robert Half, November 2025, n = 2,000+; Deel Global Hiring Report 2026.

Act 04 · Architecture

Scalable portfolio.

Integrated technical stack.

Speed

1) Light, fast and built to last

The site runs on the web's three core languages, with no framework so pages load fast and nothing breaks after a hard change.

Vanilla HTML, CSS and JavaScript: the web's native standards, with no framework, and no library, deployed as static files on GitHub Pages. No major-version migrations, no dependency to patch, full control of every byte, and a light payload that loads fast on an average phone.

Accessibility

2) Made for everyone

Anyone can navigate with a keyboard or a screen reader, with text readable in light and dark themes, on a phone or a wide screen.

Built to WCAG AA: every meaningful image carries alt text, every control is reachable by keyboard with a visible focus state, and contrast is verified in both themes. Responsive layout resolves at three declared breakpoints: <767px, 768–1023px, and ≥1024px.

Copy

3) Every word in its place

Every word lives in one of three dictionary types: text every page shares, text every case brief shares, and text for one page only.

Internationalization (i18n) runs on three layers of JSON dictionaries, merged in order: global for site chrome, regional for the strings every brief shares, local for each brief's own copy. Every string sits under one key at one level, and each English locale file has a Spanish twin with the same keys, checked by script. Spanish is transcreated, not translated.

Design System

4) The same scaffold on every brief

Every case brief uses the same interface components as templates: editorials, cards, panels, charts and dashboards.

The web applies principles from Atomic Design and DesignOps. Global tokens for color, type and spacing feed atoms such as buttons and tags, molecules such as cards and reveal panels, and organisms such as this schedule and dashboard. Each brief builds the same organisms from its own data and dictionary, so one fix lands everywhere, and every change is checked at three page widths, two themes and two languages.

Act 07 · Reflection

True legacy.

Key takeaways.

Governance

Checkpoints that hold

A run stops at every gate until I release it. Review happens on localhost before changes reach the live browser.

Tracking

One-time decisions

Every decision becomes a numbered ruling in one log, and every edit I make is recorded without a project controller.

Audience

Effective communication

Every claim traces to its source and is written for professionals outside systems engineering.
