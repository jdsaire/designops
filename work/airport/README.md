| File | Who it's for |
|---|---|
| [`index.html`](index.html) | Anyone changing the brief: markup, inline styles and scripts, in one file |
| [`i18n/`](i18n/) | Anyone changing the brief's copy: its own English and Spanish dictionaries, same keys in both, on top of the briefs' shared layer in [`../../assets/i18n/briefs/`](../../assets/i18n/briefs/) |
| [`img/`](img/) | The five slide illustrations of Act 03, as SVG |

Its Act 03 carousel takes its styles from [`../../assets/css/shared/carousel.css`](../../assets/css/shared/carousel.css) and, below 768, [`carousel-phone.css`](../../assets/css/shared/carousel-phone.css), and its behaviour from [`../../assets/js/core/carousel.js`](../../assets/js/core/carousel.js).
