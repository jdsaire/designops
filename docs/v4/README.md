# docs/v4

Governance for the S5 trust-verify migration — the first deployment under this repo's `docs/v{N}`
archival convention since Wave 6 (`docs/v3/`). The S0–S4D deploys (`deploy/v4-s1-defect-inventory`
through `deploy/v8-s4d-home-directed`) did not use this convention; this is the next version folder
per the pattern `v1`/`v2`/`v3` establish.

- `cc-plans/` — the approved plan(s) for this deployment.
- `cc-completion-reports/` — the completion report for this deployment.
