# docs/v4

Governance for the S5 trust-verify migration, the S6 Airport brief, the S8 global mechanisms, the
S10-A Portfolio Evolution brief and its review iteration, the S10-C Main organism hygiene pass,
the S10-B about/ journey, the S10-D Contact organism, the PR #35 Main closing build and the PR #36 public CVs — the deployments under this repo's
`docs/v{N}` archival convention since Wave 6 (`docs/v3/`). The S0–S4D deploys
(`deploy/v4-s1-defect-inventory` through `deploy/v8-s4d-home-directed`) did not use this convention;
this is the next version folder per the pattern `v1`/`v2`/`v3` establish.

- `STANDING-RULES.md` — rules that outlive the run that introduced them, each with its reasoning.
- `cc-plans/` — the approved plan(s) for these deployments.
- `cc-completion-reports/` — the completion report for each executed run.

The most recent run archived here is **PR #36 · Public CVs** (deploy v23). About's hero offers the locked CV in
the reader's language, as PDF and Markdown, and follows a language switch without a reload; the placeholder files are
gone. The run before it was **PR #35 · Main closing build** (deploy v22).
