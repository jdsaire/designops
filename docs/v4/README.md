# docs/v4

The records of every run from S5 (September 2026) on: the plan approved before each one, the report written after it, and the standing rules that outlived them. Which pull request each run shipped, and what it changed for a reader, is in [`../../CHANGELOG.md`](../../CHANGELOG.md).

| Path | Who it's for |
|---|---|
| [`STANDING-RULES.md`](STANDING-RULES.md) | Anyone making a change: rules that outlive the run that introduced them, each with its reasoning |
| [`cc-plans/`](cc-plans/README.md) | The plan approved for each run |
| [`cc-completion-reports/`](cc-completion-reports/README.md) | The completion report for each run |

The S0–S4D runs (pull requests #18–#21) kept no plan or report in this repository; this folder continues the `v1`/`v2`/`v3` pattern from S5.
