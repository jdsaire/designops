Design system · motion layer

Native motion, no libraries

Six specimens. Each maps a motion capability to the platform API that delivers it and the tool it replaces. Everything animates on the compositor, ships a static end-state, and honours reduced motion. One file, zero dependencies.

01 · Scroll choreography

Elements enter as the page moves

Native: animation-timeline: view() — compositor-threaded, zero JavaScript. Replaces GSAP ScrollTrigger.

Reduced motion → rows render in place, fully opaque. Same layout, no entrance.

02 · Page-to-page continuity

The browser carries elements between states

Native: document.startViewTransition() — same-document. Cross-document navigation uses @view-transition { navigation: auto }; see the spec. Replaces an SPA framework.

Reduced motion → layout swaps instantly. No interpolation plays.

03 · Sequenced timeline

A composed timeline, scripted like a storyboard

Native: Web Animations API — element.animate() with per-element delay, duration, and easing. Replaces After Effects for interface sequencing.

Reduced motion → the play control resolves the sequence instantly to its end-state.

04 · Vector draw-on

A stroke draws itself along its path

Native: SVG stroke-dasharray / stroke-dashoffset with pathLength normalisation. Replaces Illustrator line-build exports.

Reduced motion → the path renders fully drawn. That is also its resting state.

05 · Compositing

Clip, mask, and blend — moved by transform alone

Native: clip-path frames the field, mask-image fades the type's base, mix-blend-mode: difference inverts on contact. The only animated property is transform. Replaces Photoshop compositing.

Reduced motion → the field rests at the frame edge; the type is fully legible, nothing moves.

06 · Depth

Three planes, one perspective

Native: transform-style: preserve-3d with a parent perspective; children sit at distinct translateZ depths. Replaces WebGL for flat-brand depth.

Reduced motion → the card holds flat. All three layers remain readable.
