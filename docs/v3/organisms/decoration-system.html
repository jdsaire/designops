Organism · decoration system

Decoration system

Every pattern the site decorates with, live, on the shipped code. A decoration earns its place with one role (message, interaction or aesthetic), stays inside the budget, and meets the floor. It draws a bar, an edge, a fill or a line, never the words.

  • Final frameReduced motion, no JavaScript and print all show the end state, in the same layout.
  • Nothing flashesThe largest change in one place is a 1 px edge or a 4 px meter.
  • Text is never hidden or delayedTwo named exceptions: About's count-ups (X-3) and the hero entrance (X-4).
  • Contrast and focus intactNo pattern uses outline, changes a text colour or lowers an opacity of text.

03 · RUN · message

An edge passes through the order

A 1 px brand-purple edge lights each item in reading order, once: --stagger-run 140 ms between items, --hold-run 360 ms each, fading over --duration-ui. The edge is a layer (opacity only), never outline. A long pass shortens its step so it lets go by 1.2 s. Used on 12 components (timelines, ladders, the journey, the relays). Reduced motion → no pass.

04 · EMPHASISE · message

The pass lands on the key item

When RUN reaches the key item its edge swells 6 % and settles (scale 1 → 1.06 → 1, 500 ms); the words stay still. The item then rests in its own state, here the 2 px border. Used on Brief 03's journey ("the missing channel") and act 5's hand-off baton. Reduced motion → the key item's own state.

05 · GROW + RELATE · message

When, for how long, and what had to finish first

Each Gantt fill grows from its start behind its label (scaleX on a fill layer, 500 ms, 80 ms apart, 700 ms of stagger at most). Each dependency line starts as the bar it leaves finishes, revealing along its direction through a mask, so it keeps its 5/4 dash; its head appears as it arrives. stroke-dashoffset is the one non-compositor property (motion spec S4). Reduced motion → full bars, dashed lines.

The map is live and explorable

12 · TOKEN · message

The passenger walks the flow once

Brief 03's flowchart on desktop: a token walks the path when the chart is first seen, lighting each step it passes, then fades; the loop stops after the walk. Reduced motion → the final frame.
