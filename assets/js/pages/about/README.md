# assets/js/pages/about/

About's scripts. The page loads [`main.js`](main.js), which imports the rest.

| File | Who it's for |
|---|---|
| [`main.js`](main.js) | About's entry: the core engines, the two manifesto carousels ([`../../core/carousel.js`](../../core/carousel.js)) and the features below |
| [`evolution.js`](evolution.js) | The milestones: one S10-B journey per arc, one entry open at a time, reading position on the square nodes, the filter (hidden on Lab) |
| [`slogan.js`](slogan.js) | The display titles' fit: each title sized to its column and, with its label and subline, to the viewport. About's arcs and the Contact page |
| [`cv.js`](cv.js) | The CV downloads, switched to the reader's language |
