# about/

The About page, served at `/about/`: the journey, the credentials and the CV downloads. The page and its own English and Spanish copy live here; what it shares with other pages lives in [`../assets/`](../assets/README.md).

| File | Who it's for |
|---|---|
| [`index.html`](index.html) | Anyone changing the page's markup. It loads its script from [`../assets/js/pages/about/`](../assets/js/pages/about/README.md) and its own styles from [`../assets/css/pages/about/`](../assets/css/pages/about/README.md) |
| [`i18n/about.en.json`](i18n/about.en.json), [`i18n/about.es.json`](i18n/about.es.json) | Anyone changing About's copy. Same keys in both languages, in page order |

The CV files the page offers are in [`../assets/docs/`](../assets/docs/README.md).
