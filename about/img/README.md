# about/img

The six illustrations of About's two manifesto carousels (PR #43, G4), one per slide:

| File | Slide |
|---|---|
| `lab-s1-desk.svg` | Lab 1 · An independent product lab |
| `lab-s2-review.svg` | Lab 2 · AI direction and code review |
| `lab-s3-room.svg` | Lab 3 · Back to the corporate league |
| `pre-s1-tarmac.svg` | Pre-Lab 1 · Payment mockup for the new terminal |
| `pre-s2-office.svg` | Pre-Lab 2 · Operations in critical national assets |
| `pre-s3-classroom.svg` | Pre-Lab 3 · Six years in university classrooms (since PR43-Q30) |
| `pre-s3-sash.svg` | retired with the old Pre-Lab 3 (education); no page uses it, kept until its deletion is approved |

They follow the briefs' Act 03 drawings (`work/*/img/act3-*.svg`): 768×512, a transparent ground, a soft purple glow,
one solid purple object and `#9A6BFF` line work, so they read on the dark and the light theme alike. They are
schematic on purpose: no text, no logos, no names and no screens of real apps (code is drawn as bars).

They carry no `<title>`: each `<img>` takes its alt text from the page dictionaries (`about_lab_s1_alt` …
`about_pre_s3_alt`, from the About copy lock), so the description swaps language with the page.

Each slide's frame carries the "Illustration" tag (`ui_illus_label`), as in the briefs.
